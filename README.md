# 지역별 의료이용 분석 프로젝트

프로젝트 루트 `C:\mini2`에서 실행한다. 원본 엑셀과 변환 전후 자료는 처리 단계가 달라 각각 보관한다.

## Python 파일별 역할

| 파일 | 역할 | 입력 → 결과 |
|---|---|---|
| `hsyonii/파일변환.py` | 원본의 필요한 시트를 추출하고 이어지는 페이지를 합쳐 CSV로 변환 | `data/02~05*.xlsx` → `hsyonii/csv_before/`의 CSV 48개, 변환목록·원본주석 |
| `hsyonii/의료이용_전처리.py` | 세 진료 항목 추출·지역별 병합·인구 연결·이용률·인구당 이용량·정규화·순위 계산 | `hsyonii/csv_before/` → `hsyonii/csv_after/`의 분석 CSV 8개. 중간 CSV 없이 처리 |
| `hsyonii/시각화.py` | 지도 6개와 관외 이용률 상위 15개 지역 막대그래프를 Matplotlib 창에 표시 | 지역별 지표·SGIS 경계 → 화면 표시. 그림·통합 경계·매칭 CSV 자동 저장 안 함 |
| `hsyonii/access_token.py` | SGIS 인증을 요청해 액세스 토큰을 발급 | 로컬 인증 설정 → 메모리의 토큰. 경계 캐시가 없는 경우 시각화 코드가 사용 |
| `hsyonii/의료공백_크롤링.py` | Playwright로 기사 페이지를 열고 BeautifulSoup으로 제목·게시일·매체를 추출, 사례별 정리 | 공개 보도 10개 → 보도목록·사례정리 CSV, 서론자료 문서 |

## 실행 순서

```powershell
python hsyonii/파일변환.py
python hsyonii/의료이용_전처리.py
python hsyonii/시각화.py
```

첫 단계의 변환 CSV가 이미 있다면 필요한 후속 단계부터 실행해도 된다.
`access_token.py`는 별도로 실행할 필요가 없으며, 경계를 새로 받을 때 시각화 코드에서 가져온다.

크롤링은 의료이용 분석과 독립적으로 실행한다.

```powershell
# 다음 뉴스 검색에서 기사 주소를 자동으로 찾고 2025년 기사 정보를 수집
python hsyonii/의료공백_크롤링.py --search

# 실제 웹페이지에 접속해 새로 수집
python hsyonii/의료공백_크롤링.py --refresh

# 기존 수집 자료로 결과만 다시 정리
python hsyonii/의료공백_크롤링.py
```

`--search`는 `응급실 운영 중단`, `보건지소 의사 부족`, `야간 진료 축소`를 각각 2025년 기간으로 검색해 2페이지씩 확인한다. 다음 뉴스 기사 URL을 중복 제거하고 개별 페이지의 최초 게시일이 2025년인지 다시 검사한다. 검색 기간만으로 연도를 확정하지 않는다.

자동 발견 주소는 `hsyonii/csv_before/의료공백_2025/자동검색_수집대상.csv`, 검색·실패 기록은 같은 폴더의 `자동검색_수집기록.json`, 기사 정보는 `hsyonii/csv_after/2025_의료공백_자동검색_보도목록.csv`에 저장한다. 기존에 검토한 10개 보도·7개 사례 결과는 덮어쓰지 않는다. `--search --refresh`는 발견한 기사도 캐시 대신 웹에서 다시 읽는다.

검색 결과의 순서와 노출 기사 수는 실행 시 달라질 수 있다. 수집 범위는 다음 뉴스 검색 결과 일부이며 전국 전수조사가 아니다. 자동 결과는 미검토 자료이므로 관련성, 원인, 계획과 실제 시행, 동일 사건 여부를 원문으로 확인한 뒤 보고서에 사용한다. URL 중복 제거는 사건 중복 제거와 다르다.

## 폴더별 역할

- `data/*.xlsx`: 사용자가 제공한 원본 5개. 현재 변환 코드는 02~05 파일을 사용하며 01 전국시도 원본도 보존한다.
- `hsyonii/csv_before/02~05.../`: 지역 묶음별 엑셀에서 변환한 원본 표 48개.
- `hsyonii/csv_before/변환목록.csv`, `원본주석.json`: 변환 출처와 원본 각주.
- `hsyonii/csv_before/의료공백_2025/`: 기사 주소(`수집대상.csv`), 검토한 사례 분류(`사례분류.csv`), 보도 메타데이터 10개와 수집 기록. 주소·분류는 이 CSV에서 수정한다.
- `data/maps/2025_시도.geojson`: SGIS 원본 경계 캐시 17개. 시각화 재실행에 필요하다.
- `hsyonii/csv_after/`: 이용량·정규화·권역 비교·순위 결과와 보도·사례 정리 결과.

같은 이름의 표라도 서로 다른 지역 묶음의 자료다. 원본·중간 자료·분석 결과·수집 캐시는 역할이 달라 중복 파일로 삭제하지 않는다.

## 지도와 지표 해석

- 지도는 252개 세부지역(세종 포함), 시도별 분석은 17개 시도를 사용한다. 합계 행을 하위지역과 함께 합산하지 않는다.
- 관외 이용률은 관외 입내원일수 / (관내+관외 입내원일수). 시군구 경계 밖 이용 기준이다.
- 질환별 지도는 인구 천명당 입내원일수를 각 질환 안에서 0~1 정규화한다. 다른 질환의 같은 색이 같은 절대 이용량을 뜻하지 않는다.
- 막대그래프는 정규화값이 아닌 실제 관외 이용률 상위 15개 지역을 표시한다. 코드의 `TOP_N`으로 지역 수를 바꿀 수 있다.
- SGIS의 2025년 경계를 사용한다. 원본 일부 도형을 복구하고 50m 이내에서 단순화해 표시한다. Matplotlib에서 EPSG:5179 좌표를 그대로 사용한다.
- 경계와 자료의 지역명을 1:1 검사하며, 불일치가 있으면 콘솔에 해당 목록을 출력하고 중단한다.
- 고령인구 비율과 의료 중심지까지 이동시간은 현재 자료에 없다. 가설의 유의성·인과관계를 검증한 결과가 아니다.
- 의료급여 구 단위 자료 배분에 관한 원본 각주를 확인해야 한다. 인구당 수치의 분모는 의료보장 적용인구다.
- 원본 파일명의 2025와 실제 통계 기준연도가 같은지는 발간자료에서 확인해야 한다.
- 후속 비교는 권역별 박스플롯, 거리와 관외 이용률의 산점도, 고령인구 비율과 질환별 인구당 이용량의 산점도를 사용할 수 있다. 거리·고령인구 자료가 필요하다.

SGIS 공식 경계 문서: https://sgis.mods.go.kr/developer/html/newOpenApi/api/dataApi/addressBoundary.html#hadmarea

## 크롤링 자료의 범위

최초 게시일이 2025년인 보도 10개를 수집하고 같은 사건을 묶어 7개 사례로 정리했다.
제목·날짜·매체는 웹 자동 수집, 기관·지역·원인·중단 범위는 원문을 검토해 `사례분류.csv`에 적은 정보다.
전국 전수자료나 지역별 발생률 비교 표본이 아닌 서론용 사례집이다. 중단 계획과 실제 중단, 부분 제한과 전체 폐쇄를 구분한다.
출처와 세부 내용은 `hsyonii/csv_after/2025_의료공백_서론자료.md`에서 확인한다.

## 필요한 패키지

- 엑셀 변환: `openpyxl`
- CSV 전처리·분석: `pandas`
- 지도: `geopandas`, `matplotlib`, `requests`
- 크롤링: `playwright`, `beautifulsoup4`, `pandas` (현재 PC의 Edge 사용)

의료공백 크롤링에는 requests를 사용하지 않는다. requests는 SGIS 인증·경계 다운로드에서 사용한다.
