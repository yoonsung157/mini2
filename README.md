# 의료이용 지역 분석 데이터 전처리

## 실행

저장소 루트에서 아래 명령을 실행하면 `data/01_*.xlsx`의 전국 시도 집계 시트를
전처리해 `hsyonii/processed_data/`에 CSV 세 개를 생성합니다.

```powershell
python -m pip install -r requirements.txt
python hsyonii\hsy_processing.py
```

전국 시도 단위 분석에는 전국 집계 파일만 사용합니다. 지역별 보조 파일을 함께
합치면 전국 파일에 이미 포함된 시도 값이 중복될 수 있습니다.

## 생성 데이터

- `regional_summary.csv`: 지역명, 적용인구, 진료실인원, 진료비, 급여비
- `regional_in_out.csv`: 지역명, 전체/관내/관외 진료실인원
- `chronic_disease.csv`: 지역명, 고혈압/당뇨 진료실인원

각 파일은 시도 17개를 한 행씩 포함합니다. 진료비와 급여비는 원자료 표시 정밀도에
맞춰 정수 천원 단위로 반올림했으며, 인구는 의료보장 적용인구입니다. 지역별 진료비 비교에는 예를 들어
`진료비 / 적용인구`로 인구당 진료비를 계산할 수 있고, `진료실인원 / 적용인구
* 1,000`으로 인구 1,000명당 진료실인원을 계산할 수 있습니다.

## 원자료 기준

- `10p` 시트: 지역별 의료보장 적용인구
- `18p` 시트: 지역별 전체 진료실인원, 진료비, 급여비
- `20p`, `22p` 시트: 관내 및 관외 진료실인원
- `42p` 시트: 고혈압 및 당뇨 진료실인원

CSV는 Excel에서 바로 열 수 있도록 UTF-8 BOM으로 저장합니다.
